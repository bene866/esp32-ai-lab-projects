# ESP32 AI Lab Projects

This draft repository is intended for project documentation, setup notes, demo media, and example-code organization for ESP32 AI Lab kits. It should not be used as a link farm. Each project should provide technical value first and link to the shop only where it helps the builder find the exact hardware.

## Project Directories
- `led-matrix-demo/`
- `voice-quadruped-robot/`
- `stm32-self-balancing-car/`
- `aiot-learning-kit/`

## Repository Policy
- Keep READMEs English-first.
- Put build notes, demo behavior, and setup status before product links.
- Use real images, videos, or code paths only after they exist.
- Mark untested wiring, firmware, or calibration notes as draft.
- Link to one related tutorial and one related product page per project.
