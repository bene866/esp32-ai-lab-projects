# AIoT Learning Kit

Project documentation for an AIoT learning kit family covering Arduino-compatible electronics, IoT sensors, smart home demos, vision experiments, and robot-car learning paths.

## Overview
This project organizes setup notes and learning paths for the AIoT Learning Kit. It should help reviewers compare package versions and prepare practical tutorials without overstating untested behavior.

## Features
- Beginner-to-advanced package path notes
- Sensor, IoT, smart home, vision, and robot-car demo directions
- Package/version comparison support
- Draft setup notes for tutorial review

## Hardware List
- Arduino-compatible controller option
- Sensor starter or advanced modules
- IoT and display modules
- Smart home package option
- EBot robot car option
- Vision recognition demo option

## Quick Start
1. Select the package version.
2. Confirm the included modules.
3. Start with one sensor data collection demo.
4. Add smart home, robot car, or vision modules only after the base demo works.
5. Record package differences for the buying guide.
