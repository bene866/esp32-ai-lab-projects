# LED Matrix Demo

ESP32 16x16 LED matrix demo notes for basic wiring, first animation effects, and short visual tests.

## Overview
This project documents a small LED matrix build using an ESP32 controller and a 16x16 programmable pixel panel. The goal is to keep wiring, power, and first-demo notes easy to review before publishing a fuller tutorial.

## Features
- 16x16 LED matrix animation tests
- Rainbow, fire, starfield, and countdown demo directions
- Beginner-friendly ESP32 setup notes
- Draft status until wiring and demo code are rechecked

## Hardware List
- ESP32 board
- 16x16 programmable LED matrix
- Power module or suitable USB/battery power setup
- Jumper wires

## Quick Start
1. Confirm the LED matrix voltage and power needs.
2. Connect data, power, and ground according to the validated wiring note.
3. Load the starter animation sketch.
4. Run a low-brightness first test.
5. Record any flicker, power, or pin changes.
