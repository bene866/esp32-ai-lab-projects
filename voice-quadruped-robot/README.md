# Voice Quadruped Robot

Build notes for a compact voice-controlled quadruped robot demo focused on servo leg movement, basic actions, and reviewable setup documentation.

## Overview
This project is for documenting the quadruped robot assembly path, movement test flow, and voice interaction notes. It should help builders understand the hardware before they follow a full tutorial.

## Features
- Four-leg walking robot structure
- Servo-driven movement demos
- Voice interaction setup notes
- Color, firmware, and calibration notes after verification

## Hardware List
- Quadruped robot body parts
- Servo leg mechanism
- Controller board
- Wiring set
- Power source suitable for servo load

## Quick Start
1. Inspect the servo orientation and leg parts.
2. Assemble one leg and verify motion range.
3. Connect the controller and power.
4. Run a basic movement test.
5. Add voice interaction only after movement is stable.
